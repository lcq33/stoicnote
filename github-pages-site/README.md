# 斯多葛日常规划

一个单文件为主的移动端网页应用，可直接部署到 GitHub Pages。

## 使用

1. 打开 GitHub Pages 网址。
2. 在手机浏览器中使用，或通过浏览器菜单添加到主屏幕。
3. 数据保存在当前浏览器的 localStorage 中。
4. 在「备忘」页使用「导出数据 / 导入数据」进行备份和恢复。

## 部署到 GitHub Pages

把本目录作为仓库内容推送到 GitHub，然后在仓库 Settings -> Pages 中选择：

- Source: Deploy from a branch
- Branch: main
- Folder: /root

保存后等待 GitHub Pages 生成访问链接。
